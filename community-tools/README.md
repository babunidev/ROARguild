# Community tools

This folder documents software concepts and integrations intended to support the ROAR community.

The documents here describe purpose, desired behavior, requirements, and unresolved design questions. They do not prove that a tool has been implemented, tested, or deployed. Source code should live in a separate repository unless that boundary is explicitly changed.

## Current concepts

- [The Oracle](ORACLE.md) — a developing concept for an autonomous AI guild Game Master that uses Discord activity and character information to support community memory, stories, quests, and recognition.

## Documentation rules

- Label concepts and features by their actual status.
- Separate user-defined design requirements from assistant suggestions and unresolved questions.
- Do not invent integrations, APIs, permissions, or implementation details.
- Do not store member profiles, private Discord messages, credentials, or other personal data in this public repository.
- Resolve transparency, consent, access, retention, and deletion expectations before member-data collection is treated as ready for use.
