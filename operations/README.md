# Operations

This folder is reserved for practical documents needed to run the guild.

Potential subjects include:

- Recruitment and welcoming new members.
- Communication channels and in-game announcements.
- Event coordination.
- Role and responsibility handovers.
- Moderation and conflict handling.
- Administrative checklists.

**Current status:** these procedures have not yet been defined. Add operational instructions only after the relevant approach has been agreed. Keep private member data, credentials, and sensitive records out of this public repository.
