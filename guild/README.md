# Guild documentation

This folder contains the living documents that describe the guild itself.

## Documents

- [Charter](CHARTER.md) — working principles and the intended character of the guild.
- [Community](COMMUNITY.md) — the atmosphere and boundaries the community is intended to uphold.
- [Governance](GOVERNANCE.md) — responsibilities and decision-making; currently unresolved.
- [Activities](ACTIVITIES.md) — the initial focus and possible shared activities.

## Current status

The initial direction is an Alliance roleplaying community in World of Warcraft Forever. ROAR remains the project identity, while the final in-game name, formal charter, governance model, and event schedule are not yet settled.

The Oracle is documented separately as a community-tool concept in [community-tools/ORACLE.md](../community-tools/ORACLE.md). It should not be treated as an existing guild officer or implemented governance system.

These documents are working material. A draft is not automatically an adopted guild rule.
