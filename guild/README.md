# Guild documentation

This folder contains the living documents that describe the guild itself.

## Documents

- [Charter](CHARTER.md) — working principles and the intended character of the guild.
- [Community](COMMUNITY.md) — proposed expectations for how members treat one another.
- [Governance](GOVERNANCE.md) — responsibilities and decision-making; currently unresolved.
- [Activities](ACTIVITIES.md) — the initial focus and possible shared activities.

## Current status

The initial direction is an Alliance roleplaying community in World of Warcraft Forever. The final in-game name, formal charter, governance model, and event schedule are not yet settled.

These documents are working material. A draft is not automatically an adopted guild rule.
