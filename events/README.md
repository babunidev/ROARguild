# Events

This folder contains event concepts, plans, and records.

## Organization

Create one folder for each recurring event series. One-off events may use a dated file or a clearly named folder, depending on how much material they need.

## Event lifecycle

Use clear status labels:

- **Proposed** — an idea under consideration.
- **Planning** — organizers, format, and practical details are being worked out.
- **Scheduled** — date, time, timezone, and location have been confirmed.
- **Completed** — the event took place; record only what actually happened.
- **Paused** or **Retired** — the series is not currently active.

## Planning checklist

Before describing an event as scheduled, confirm its organizer, date, time and timezone, location, format, and any practical requirements. Never invent these details.

Use the template in templates/event-template.md when it is useful.
