# ROARguild

The project home for shaping and documenting the ROAR guild community in **World of Warcraft Forever**.

ROAR is currently being explored with an initial focus on an **Alliance roleplaying community**. The project is intentionally allowed to evolve: its final guild identity, charter, governance, and recurring activities are not all settled.

## Project status

This is a living project, not a finalized guild handbook. Documentation distinguishes between:

- **Established** — a direction or constraint already agreed.
- **Developing** — an idea being actively shaped, but not yet finalized.
- **Proposed** — an option for consideration.
- **Open** — a decision that has not been made.

The name **Amberhearth** has emerged as an alternative identity, but it has not replaced ROAR as the project identity. Sunday road bonfires or campfires are a developing activity concept, not yet a confirmed event schedule.

## Repository scope

This repository documents the **guild and its community**. It is separate from the RoarForever World of Warcraft addon repository; addon source code and technical implementation do not belong here.

The initial scope is World of Warcraft Forever and an Alliance roleplaying focus. Possible future chapters for other factions or rulesets are not part of the initial launch scope and should only be documented as future possibilities until explicitly established.

## Working principle

**Play to inspire, not to impress. ROAR stays ROAR.**

This is a previously explored motto, retained here as a working phrase rather than a formally adopted guild motto.
