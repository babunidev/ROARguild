# Assets

This folder is for public-safe project media, such as:

- Approved guild logos and wordmarks.
- Banners and promotional artwork.
- Event illustrations.
- Screenshots intended for publication.
- Source files for editable visual assets.

No final visual identity is established by this folder's creation. Do not treat an exploratory sketch, generated image, or temporary graphic as an approved logo without an explicit decision.

Where practical, keep editable source files alongside exported versions and record the source, author, and usage rights for externally supplied material.
